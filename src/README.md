# Source

Sede futura del codice applicativo di Graph.

Sottocartelle iniziali:

- `app/`: orchestrazione del flusso applicativo.
- `domain/`: logica indipendente da librerie esterne.
- `adapters/`: adapter verso librerie Excel, charting o browser API.
- `ui/`: componenti e logica di interfaccia.

Nessun codice funzionale dovrebbe essere aggiunto senza specifica collegata.
